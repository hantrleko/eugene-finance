## 一、 总体定位：一个研究工作台，连接完整研究闭环

综合首页不是 26 个松散网站链接组成的导航黄页，而是**研究与决策统一起点**。

它同时解决三个核心工作流问题：
1. **我今天要研究什么？** —— 设定研究目标（提升学术能力、研究公司与行业、形成投资判断）；
2. **应该进入哪个工具？** —— 统一六大领域分类索引，直达对应专业计算子系统；
3. **这些工具怎样共同完成一项研究？** —— 提供首发三条研究路径（Playbooks），串联从数据、建模到交付物的完整动作。

## 三、 三大首发研究路径 (Research Playbooks)

分类解决“在哪里”，路径解决“怎么用”。第一版提供三条标准化路径，并附带可一键复制的标准化交付物 Markdown 模板：

### 路径 A：研究一家公司 (Research a Company)
- **步骤流转**：年报文本特征引擎 → 产业链利润池与Capex研究台 → 公司经营驱动与逆向DCF → 投资判断记录
- **交付终点**：完成一份《公司深度研究备忘录 (Company Research Memo)》，给出关键经营预测、逆向估值假设与明确的认错条件。

### 路径 B：完成一项实证研究 (Conduct Empirical Research)
- **步骤流转**：EF Lab理论与机制推导 → 因果识别策略论证 → A股事件研究标准化流水线 → 局限性诚实交代
- **交付终点**：一份《实证研究设计与可复现结果包 (Empirical Research Pack)》，导出LaTeX学术三线表与平行趋势检验图。

### 路径 C：形成一次可复盘的投资决策 (Auditable Investment Decision)
- **步骤流转**：Market Pulse宏观脉冲 → QuantRiskLab时点方差穿透 → 因子工作台Alpha核验 → 组合风险预算分配 → 事前概率赋值与复盘
- **交付终点**：归档一份《事前投资决策卡片与Brier复盘账本 (Pre-Mortem Record)》，事前记录主观概率，事后用Brier得分校准认知。

## 四、 本地运行与开发

```bash
# 进入工程目录
cd e:\AMP\eugene-finance

# 安装依赖
npm install

# 本地热更新开发（默认端口 5173）
npm run dev

# 静态打包编译（产物位于 dist/，base: './' 适配任意静态托管）
npm run build

# 本地预览打包产物
npm run preview
```

## 五、 技术栈与工程实践

- **前端架构**：React 18 + TypeScript + Vite 6 + Tailwind CSS + Lucide Icons
- **单事实目录管理 (Single Registry)**：所有 26 个项目的定义、状态、标签、输入输出与命令，均由 `src/data/projects.ts` 集中维护，免除多处手工修改。
- **本地偏好存储 (LocalStorage)**：工作台的 6 个常用入口与最近打开历史全部保存在用户本地浏览器，严格遵守隐私保护原则，不伪造云端同步。
- **CI/CD 自动化**：通过 GitHub Actions (`.github/workflows/deploy.yml`) 监听 `main` 分支推流，自动构建并部署至 GitHub Pages。
